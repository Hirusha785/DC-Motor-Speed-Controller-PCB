# DC Motor Speed Controller PCB

A compact DC motor speed controller PCB designed in KiCad using an **NE555 timer IC** configured as a PWM generator and a **TIP122 Darlington transistor** as the motor driver stage.

This project is suitable for controlling the speed of small DC motors using a potentiometer-based PWM control method.

---

## 📌 Project Overview

This PCB is designed to control the speed of a DC motor by varying the duty cycle of a PWM signal generated by the NE555 timer. The output PWM signal drives a TIP122 transistor, allowing the connected DC motor to run at adjustable speeds.

The board includes screw terminal connectors for power input and motor output, an onboard power indicator LED, and mounting holes for easy installation.

## 🧩 Main Components

| Reference | Component | Description |
|---|---|---|
| U1 | NE555P | Timer IC used for PWM generation |
| Q1 | TIP122 | NPN Darlington transistor used as motor driver |
| RV1 | 100K Potentiometer | Speed adjustment control |
| D1, D2, D3 | 1N4007 | Diodes for timing and motor protection |
| D4 | LED | Power indicator |
| C1, C2 | 100nF | Timing / filtering capacitors |
| C3 | 100uF | Power supply smoothing capacitor |
| R1, R2 | 1K | Current limiting / base drive resistors |
| R3 | 2.2K | LED current limiting resistor |
| J1 | Screw Terminal | DC power input |
| J2 | Screw Terminal | DC motor output |

---

## 🔌 Circuit Description

The NE555 timer IC is configured in astable PWM mode. The potentiometer changes the charge and discharge path of the timing capacitor, allowing the duty cycle of the output signal to be adjusted.

The PWM output from pin 3 of the NE555 drives the TIP122 transistor through a base resistor. The TIP122 switches the motor current on and off rapidly according to the PWM duty cycle.

A flyback diode is connected across the motor output to protect the transistor from reverse voltage spikes generated by the motor coil.
